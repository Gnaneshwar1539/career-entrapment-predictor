# 🚀 Career Entrapment Predictor

An AI-powered web application that predicts potential career entrapment risk based on user inputs using Machine Learning.

## 📌 Problem Statement

Many professionals feel stuck in careers misaligned with their skills and interests. This project aims to identify early warning signs of career entrapment using predictive analytics.

## 🛠️ Tech Stack

- Python
- Streamlit
- Machine Learning
- Pandas
- Scikit-learn
